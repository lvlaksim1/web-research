# web research v47

Стабилизация forensic checkpoints по результатам анализа реального ZIP v46.

- Удалён временной throttle, из-за которого соседние semantic checkpoints могли теряться.
- Runtime DOM elements получают стабильные уникальные page-local IDs через WeakMap.
- Native recording-boundary checkpoint выполняется атомарно вместе с instrumentation, повторяется при явном неуспехе и имеет native fallback с warning вместо молчаливой потери.
- Ввод текста фиксируется как debounced `before-input` / `after-input` burst, без checkpoint на каждый символ.
- Добавлены regression tests и актуализированы ARCHITECTURE/CAPTURE_MATRIX.
